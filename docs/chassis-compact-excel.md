# Compact Chassis Analysis and native Excel exports

The approved preview is applied only to Chassis Analysis (`#s9`, logical slide 10). Cards, headings, table padding and canvas height are compact; wide tables scroll internally rather than widening the page. The summary/chart/calendar/count section order is preserved. Duplicate Copy/PNG actions are removed from this slide. Other slides retain their existing actions and styles; dark and light themes remain supported.

The existing renderers still select the largest positive Plan/Day product for each master Line/Date, use the configured chassis priorities/strengths and calculate all loading, Hit/Not Hit and item-count values. The preview CSV is not included or read by the live implementation. The live tables continue to use the current selected MySQL-backed plan.

Each requested table has one native `.xlsx` download link. It reads every rendered table row and column, including cells outside both scroll viewports. Values, line breaks, rich date headers, number/percentage precision, leading zeros, fills, fonts, borders, alignment, row heights, column widths and merged ranges are written as Office Open XML. Formula-like text stays text. Excel's font/DPI rendering can differ slightly from browser pixels. The file name identifies the current selected file and the exported date range. Header/identity columns are frozen.

Exports are blocked when signed out, outside Chassis permission/scope, while planning is loading/failed, for mismatched upload versions or when the report is empty. Existing Blob links are revoked when planning refreshes, the calendar renders again, or the account logs out. Downloads use the actual user-clicked anchor to support embedded browsers.

Validation uses production markup/renderers with synthetic selected-plan data, not private reports. The test compares all five existing table payloads before/after styling, and checks 4,086 cells across both themes by independently opening native ZIP/XML sheets and styles. It covers offscreen rows/columns, source-based filenames, freeze panes, merged cells, Unicode, leading zeros, formula-like strings, empty-data/permission/version guards, range filtering, and viewport widths 784/1065/1464/1920. Code-only packaging verifies both new assets and excludes source files, demo CSVs and server configuration. Existing calculation/cache/source regressions remain in CI.
