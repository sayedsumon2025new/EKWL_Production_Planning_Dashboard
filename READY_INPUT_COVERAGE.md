# Ready Input Coverage — Slide 21

The second table measures cutting-hand ready input against 100% of the next three **calendar** days' planned quantities. Each Day cell is dark green #14532d when all required colors cover cumulative demand, dark red #7f1d1d when a verified shortage exists, and grey #475569 when evidence is incomplete. Text is white. There is no colored Run Status column.

Dates: MAX(date_wise_production.output_date) + 1/2/3, never the current date or next working days. Eligible EWO: positive actual output at that cutoff and positive plan within the window in the selected completed upload. One pooled EWO row combines demand across its planning lines so shared cut stock is not repeated per line. Zero daily cells must actually exist; missing rows/values are not assumed zero or off-day. Off-day requires known zero planning across all eligible master-line Plan/Day records for that date. A prior missing date makes later cumulative coverage unknown.

Sources: plan_uploads/plan_records/plan_daily; fabric_cutting_info total_cut_qty (finished cut pieces, not cutable fabric); sewing_input_output total_input_qty across every line by EWO/color; active embellishment_send_receive_rows latest cumulative Print/EMB receives less returns. EWO/color normalization uses existing readiness helpers. All source reports are read only.

Ready balance: matched eligible cut pcs minus already-input pcs. No-process colors use cut pcs. Print-only or EMB-only colors use the smaller of cut pcs and valid net completed receipts, then subtract input. Both Print and EMB required, mixed processing flags, duplicate/negative/conflicting values, input exceeding eligible receipts, absent reports or blank colors leave balance Unknown with a reason. Separate Print and EMB totals cannot establish that the same pieces completed both. Colors cannot cover each other's shortages. Existing sewing WIP is excluded because this feature measures stock outside Sewing, ready to input.

Stock sources are latest reports, not historical stock reconstructed as of the cutoff. Their upload/report dates are visible under Evidence. The cutoff only anchors the three-day planning window. Existing report tables do not supply full dated stock movements or a shared-piece completion identity for the two embellishment processes; these limitations are disclosed rather than inferred.
