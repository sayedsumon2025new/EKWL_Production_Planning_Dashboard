Daily loss = max(0, Target − Forecast)। Planning / Loading Gap = min(daily loss, max(0, Target − Plan))। Allocated Print / Embroidery WIP qty × EWO SMV / 60 goes to its own delayed row first. Remaining loss budget EWO-wise uncovered SAH-তে assign হয়। Over-target planning হলে EWO reason allocation proportionally cap হবে, যাতে reason total daily loss-এর বেশি না হয়।
