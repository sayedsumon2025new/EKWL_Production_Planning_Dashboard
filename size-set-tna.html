Metric definitions

OTD = on-time completed ÷ (all completed by the as-of date + overdue open). A milestone is on time when Actual ≤ Plan. An uncompleted milestone is overdue only when Plan is before the as-of date; milestones due today are tracked separately. Future actual dates count as uncompleted until reached. Upcoming milestones are excluded from OTD. Size-set completion counts source rows with a valid Bulk Pattern Actual on or before the as-of date. Each SS.csv row is a separate report record; repeated EWO/color rows are retained. This completion KPI uses all milestones of the filtered source rows, regardless of the milestone filter. Blank Plan dates are excluded from timing. An actual-only Bulk Pattern still counts toward size-set completion and appears in its completion drilldown. Current owner uses Who from the report; Pattern Master Name is a fallback only for pattern milestones. Filters apply to the charts, KPIs and tracker; milestone selection does not change the record-level completion denominator. Yearless Plan dates use the valid date nearest an explicit EFD; yearless Actual dates use the year nearest Plan or EFD. This is date inference, not a source fact. Without an anchor, the date is excluded. Choose explicit years only below to disable inference.
